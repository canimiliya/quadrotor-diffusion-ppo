# S2-R0 report

The report is generated by `scripts/run_s2_dataset.py` and the authoritative
machine-readable result is `artifacts/s2/summary.json`. A PASS requires 360
accepted trajectories, 28/6/6 task-level splits per scene, finite compact NPZ
files, deterministic task generation, deterministic OPEN/BLOCK/SBEND rollout
smoke checks, and the unchanged M0 regression suite.

This stage proves availability of a balanced privileged-teacher expert dataset
for the next Diffusion-only imitation stage. It does not prove that Diffusion,
BC, PPO, sample efficiency, collision reduction, or generalization works.
